Photo helper

Resize phone photos, name them after each part, and get a ready-to-upload folder.

1. Which parts still need a photo?

Checking your catalog…

Show parts without a photo

    2. Choose your photos

    Plain surface, daylight, the whole part in the picture. If a photo file is already named after the part's SKU (like ENG-0001.jpg), it is matched automatically. Do about 20 to 40 photos at a time.

    3. Match each photo to a part

    Click the box under a photo and start typing the part name or SKU, then pick it from the list.

    4. Put them on the website

    1. Find the downloaded ZIP, right-click it and choose Extract All.
    2. Open the extracted folder. Inside is a folder called img.
    3. On GitHub, open the malikautoz-shop repository, click Add file → Upload files, and drag the whole img folder onto the page.
    4. Click Commit changes. In about a minute the photos appear on the shop page. If GitHub complains about too many files, upload in smaller batches.

    A new photo for a part that already has one simply replaces it. Photos are made about 800 pixels wide, usually under 100 KB each.
